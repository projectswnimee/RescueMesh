# 🧱 3D Printed Enclosure  
## Power Path Management Circuit Housing  

---

## 📌 Description
This enclosure is designed to securely house the **Power Path Management Circuit**, including the LiPo charger, boost converter, and related components.

### ✅ Key Features
- Physical protection  
- Compact organization of components  
- Easy access for USB input and output connections  

---

## 📁 Folder Structure
- **Blender File/** → Original `.blend` design file  
- **Stl/** → STL files for 3D printing  
- **Cura/** → Slicing files / configurations  
- **enclosure object mode.png** → Preview image of the enclosure  

---

## 🛠️ Design Details
- Designed using **Blender**  
- Optimized for **3D printing**  
- Compact and lightweight structure  

### 🔌 Openings
- USB input  
- 5V output  
- Ventilation (if applicable)  

---

## 🖨️ Printing Instructions
- **File format:** `.stl`  
- **Recommended material:** PLA  

### ⚙️ Suggested Settings
- Layer height: 0.2 mm  
- Infill: 20–40%  
- Supports: As required (depending on orientation)  

---

## ⚠️ Notes
- Ensure proper alignment before printing  
- Check tolerances based on your printer accuracy  
- Modify design if your components differ in size
